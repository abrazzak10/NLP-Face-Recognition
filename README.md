# Face Recognition System using CNN
This project is a Face Recognition System built using a Convolutional Neural Network (CNN) in Python with TensorFlow/Keras.
The system detects and recognizes faces from images with high accuracy.
## 📌 Features

- Face detection and recognition using CNN
- Customizable training with your own dataset
- Easily scalable to new users/faces

  ## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
  ## 📂 Dataset
  -Made by me
  The model can be trained on any structured face dataset with labeled folders for each individual.
